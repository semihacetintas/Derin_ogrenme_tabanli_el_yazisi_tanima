# Derin Öğrenme Tabanlı El Yazısı Tanıma Sistemi

Bu proje, el yazısı metinlerin görüntülerden otomatik olarak tanınmasını amaçlayan bir bitirme projesidir.

## Özellikler

- El yazısı kelime tanıma
- Cümle okuma
- Kelime segmentasyonu
- Türkçe yazım düzeltme
- Grafiksel kullanıcı arayüzü

## Kullanılan Teknolojiler

- Python
- TensorFlow
- OpenCV
- NumPy

## Çalıştırma

```bash
pip install -r requirements.txt
cd src
python read_sentence.py --img_file ornek.png
```
